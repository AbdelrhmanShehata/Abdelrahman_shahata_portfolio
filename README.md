## ▶️ Getting Started

### Option 1: Open directly
Simply open `index.html` in your browser.

### Option 2: Run local server
From the project root, run:

```bash
python -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```

### Option 3: Windows quick launch
You can also use:

```bash
open_portfolio.bat
```

## 🌍 Deployment
