## 🖥️ How to Run & Preview

### Method 1: Direct Browser Launch
Simply double-click `portfolio/index.html` (or `index.html` in the root) to open it in any modern browser (Chrome, Edge, Firefox, Brave, Safari).

### Method 2: Local HTTP Server (PowerShell / Python)
Run from the workspace directory:
```powershell
python -m http.server 8000
```
Then navigate to: `http://localhost:8000/portfolio/`

## 🌐 Free One-Click Deployment Options

### GitHub Pages:
1. Push this folder to your GitHub repository `AbdelrhmanShehata/portfolio`.
2. In GitHub repository settings -> **Pages**, choose the branch (`main`) and root folder (`/`).
3. Your site will immediately go live at `https://abdelrhmanshehata.github.io/portfolio/`.

### Vercel:
1. Import your GitHub repository into [Vercel](https://vercel.com).
2. Set root directory to `portfolio` or leave at root.
3. Deploy in under 30 seconds with automatic SSL and global CDN.
